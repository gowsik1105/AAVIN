# Aavin Thozhilar Sangam (ஆவின் தொழிலாளர் சங்கம்) 🥛

Official digital cooperative network platform connecting Aavin dairy members, Sangam administrators, district officers, and Tamil Nadu government officials.

## 🚀 Features
- **Bilingual Interface**: Seamless Tamil (தமிழ்) and English switching
- **Interactive Tamil Nadu Dairy Map**: District-level dairy processing units and Sangam points
- **Issue Ticketing & Grievance Redressal**: Real-time member complaints & resolution tracking
- **Secure Supabase Authentication**: Role-based access control for Members and Administrators
- **Modern Responsive Design**: Optimized for mobile, tablet, and desktop

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, CSS3 Design System
- **Maps**: Leaflet.js Interactive Mapping
- **Database / Auth**: Supabase

## 🏃 How to Run Locally
1. Double-click `run.bat` or `dev.bat` to launch the local server.
2. Open `http://localhost:8000` in your web browser.
